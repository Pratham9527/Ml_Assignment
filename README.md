# Machine Learning Lab Programs 🧠

This repository contains a collection of 15 machine learning programs implemented using Python.  
Each program covers a different ML concept — from basic regression to advanced clustering and neural networks.

---

## 📘 Contents

1. Linear Regression — Predicting house prices  
2. Lasso & Ridge Regression — Regularization comparison  
3. Gradient Descent — Salary prediction (Years of Experience)  
4. Non-linear Regression — China’s GDP prediction  
5. Logistic Regression — Cancer classification  
6. KNN — Customer category prediction  
7. Decision Tree — Drug recommendation system  
8. Naive Bayes — Diabetes prediction  
9. SVM — Cancer classification using different kernels  
10. Model Comparison — SVM, KNN, NB, Decision Tree on Diabetes dataset  
11. XOR Problem — Neural Network using Perceptrons  
12. Multilayer Perceptron — Iris flower classification  
13. K-Means — Customer segmentation (Euclidean & Manhattan)  
14. Hierarchical Clustering — Vehicle grouping (Agglomerative & Divisive)  
15. DBSCAN — Weather station clustering with outlier detection
